# Outliner work planning

The Outliner holds the agreed work and the evidence needed to resume it.

## Language

**Canonical work item**: One durable description of a user outcome and its acceptance criteria. Its appearances in board views refer to the same item.

**Backlog**: Captured possible work, with varying levels of definition. Ranking and refinement make an item a candidate without committing to delivery.

**Work batch**: A bounded set of canonical work items the owner has agreed to pursue together. Membership persists while the items progress; scope changes have recorded reasons.

**Next block of work**: The next agreed work batch. It promises scope, without prescribing a fixed timebox or exact execution order.

**Delivery stage**: An item's current position in execution and acceptance. It is independent of batch membership, priority and ordering.

**Superseded work**: A retired contract whose responsibility has moved to another canonical work item. Retirement is not proof of delivery.
